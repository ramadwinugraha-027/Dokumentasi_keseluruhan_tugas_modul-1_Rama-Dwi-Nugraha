# Praktikum Modul 2 - Interactive Profile Card

## Cara Menjalankan Project
Project ini menggunakan `fetch()` untuk membaca file JSON lokal (`data/profile.json`), sehingga wajib dijalankan menggunakan **Local Server**.

### 1. Menggunakan VS Code Live Server
* Buka folder project di VS Code.
* Klik kanan pada `index.html`.
* Pilih **Open with Live Server**.
