Di sini kita nggak cuma copy-paste kode atau asal pakai library. Kita belajar memahami HTML, ngatur layout dengan CSS, sampai melatih logika pemrograman lewat latihan dan review kode bareng.

Daftar Sesi Diskusi Lihat Kegiatan

Belajar Bareng, Paham dari Dasarnya

Kita mulai dari hal dasar dulu, lalu pelan-pelan naik ke materi yang lebih kompleks.

Klub Koding dibuat sebagai tempat mahasiswa bisa belajar bareng di luar jam kuliah. Nggak harus langsung jago, yang penting mau mencoba, bertanya, dan memahami cara kerja kode yang kita buat.

Setiap anggota juga diajak untuk membiasakan diri mencatat proses belajar, mencoba debugging lewat DevTools, dan belajar menggunakan Git dengan cara yang benar.

Kegiatan Mingguan

Belajar nggak cuma baca materi, tapi langsung coba dan bahas bareng.

Praktik Dasar

Klinik HTML & CSS Murni

Latihan mencari kesalahan HTML, memperbaiki tampilan dan aksesibilitas, serta membuat layout responsif tanpa bergantung pada framework.

  • Ngulik DOM & Box Model
  • Belajar Mobile-First Flexbox
  • Cek Dasar Aksesibilitas
Rutin Mingguan

Bedah Kasus & Logika C

Membahas kode C dari hal dasar sampai struktur data, pointer, dan file agar lebih paham apa yang sebenarnya terjadi di balik program.

  • Tracing Alur Program
  • Latihan Struktur Data
  • Mencari dan Memperbaiki Error
Kolaborasi

Ulasan Kode dengan Teman

Saling melihat dan memberi masukan pada kode teman, belajar membuat commit yang jelas, serta menyiapkan project agar lebih mudah dipahami.

  • Penamaan Kode yang Rapi
  • Latihan Menjelaskan Kode
  • Membuat README Sendiri
